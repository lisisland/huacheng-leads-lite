# 精简工作区设计

面向初创外贸团队的日常企业资料整理与背景核验。沿用 GoodJob 后端和权限，另设 `/focus.html`，完整系统保留。

色彩：纸白 #ffffff、冷灰 #f3f6f8、正文蓝灰 #233b4d、深海绿 #126d67、浅青 #e6f3ef、警示棕 #986125。
字体：Windows 本地 Microsoft YaHei UI / Microsoft YaHei；大标题 28px，正文 14px，辅助文字 12px。无需外部字体请求。
布局：左侧窄导航，主区工具栏和客户表格；详情在右侧抽屉展开。数据源独立为可筛选目录，运行日志折叠进任务详情。

```
品牌 | 企业资料工作区                    完整系统 / 刷新
导航 | 搜索条件（默认展开，来源主动选择）
     | 候选名单：企业 / 市场 / 来源 / 联系资料 / 核验
     |                                  企业详情抽屉
```

约束：无首页 KPI 卡片墙、无聊天式执行日志、无未经证实的“高意向”；不把创建时间当成联系人更新时间；不将来源登记或绿色默认值等同联网验证；电商尚未接入时明确说明。

复核：这一页的重点是核验企业而不是展示系统功能数量。用来源标记和证据抽屉承担差异化，删除渐变、装饰性数字和营销头图。第一版保留企业资料、数据源目录和任务留痕；销售话术、自动外发及复杂业务模块不进入新界面。
