# Public template boundary

Original example Excel files are intentionally excluded from this public source distribution. They contained prefilled sample commercial information and embedded media. Default GoodJob logos remain under their upstream license.

Configure your own sanitized templates before using Excel export for packing lists, quotations, proforma invoices, purchase contracts or supplier work orders. The corresponding code and field mappings remain in the repository. The original local installation and its templates have not been changed.

Template variable names and field mappings are documented in the source, including `backend/src/trade-document-*`. This public showcase has no bundled customer orders, bank details, signatures or stamps.
